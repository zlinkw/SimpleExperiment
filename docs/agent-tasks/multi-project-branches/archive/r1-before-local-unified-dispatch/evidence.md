## 尚待明确的唯一产品边界
- 最小方案：统一管理与查看多个分支，逐分支依次验证，复用各项目原有PLAN/GPU执行，不新增跨项目并发GPU预约机制。
- 若要求多个创新项目同时共享GPU并行验证，需明确纳入跨项目准入互斥设计；不能仅加界面却宣称已保证全局统一调度。
- 尚无业务源码修改、测试、运行版本递增或新PR，不为资料创建空PR。
