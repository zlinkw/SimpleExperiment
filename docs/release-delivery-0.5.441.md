# 0.5.441 试行交付

权威版保持 SimpleExperiment 0.5.440 / SimpleSFTP 0.2.117，精确身份见 [release-policy.json](release-policy.json)。本版本按用户新裁决仅发布 Prerelease，不替换 Latest；用户实际认可后再提升权威版本。

## 本次八项修复

1. Worker 会话检测间隔进入真实保存和草稿链路，范围仍为 1–60 秒。
2. 配置的指标别名用于主动长表、宽表和派生指标；默认分别统计 AP/AUPRC、普通与各类 F1，保留冲突拦截与历史显式配置。
3. 低流量严格手动刷新显示与结果；阻断页签/完成通知触发的自动读取，切换时取消自动结果请求，保留手动请求与必要调度、安全核实。
4. 指定 PLAN 的查询在服务器读取前缩小范围；不存在或歧义拒绝。所选查询返回独立报告，不覆盖整批结果或混入未查询的历史行。
5. 显存等待解释卡、空闲量、阈值、并行配额、预算预留、采样进度等原因。仅复用现有遥测，不修改准入条件、预算公式或 OOM 防护。
6. 汇总分别显示 Plan/job 数与未知状态，重复问题按 Worker/原因折叠，完整条目保留。
7. 配置位置改为当前项目；服务器导入按钮说明实际的 Xshell 选择与确认保存流程；旧上报参数标为兼容只读值。
8. 接入编辑器支持通用、分类、分割、回归、自定义类型，提供对应指标说明，不覆盖已有指标；使用说明与 README 同步。
