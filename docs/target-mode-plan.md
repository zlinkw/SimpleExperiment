# 目标模式当前计划：前后端静态优化周期
本文档只保留最新活动目标。历史批次、验证和部署记录以 git 提交为准。
打包/清理时会自动压缩本文件，禁止堆积流水账。

## 固定边界
- SimpleExperiment 负责计划、Agent、状态和任务；SimpleSFTP 负责真实文件传输；PPT 插件负责绘图。
- 连接边界固定为 Xshell 本地隧道 + Hub/Worker Agent + SimpleSFTP；插件不内置 SSH/SCP/rsync。
- 不迁移、删除或重写旧任务、结果和安装产物；不处理现有用户删除项、历史 VSIX 或 `zlk_cluster/ui/`。
- 当前不连接服务器，只执行本地静态检查；不重载、关闭或自动操作 VS Code。
- 每批最多 2 至 3 个强相关问题、8 个源码/文档/测试文件，并独立提交、推送到 `origin/master`。
- 每 5 个完成批次执行一次全量静态测试，其余批次执行定向检查。

- 服务器或 GPU 标识长期变化不得使 Agent 与 Webview 缓存无限增长。
