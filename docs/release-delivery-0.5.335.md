# 0.5.335 取消旧清理重连提醒

## 修复

截图通知由 PlanCleanupHost 在初次连接或隧道重连时检查历史清理请求产生。旧请求里的路径仍有文件，即会出现“文件尚未清除”提示；关闭弹窗后通知标记被释放，后续重连又会提醒。这不能代表用户对当前产物有新的清理意图。

移除遥测回调中的清理 Host 调用、重连队列、历史扫描和通知，以及清理结束后对无关历史请求的后台复查。observeConnections 仅保留无副作用的兼容入口，不读取文件、查询服务器或创建提醒。

当前覆盖重跑与用户主动清理仍使用原有真实文件查询、精确路径预览和两次删除确认。主动查询发现目标已不存在时继续退出审核索引。未自动删除旧记录、用户产物或其他文件，没有改动任务执行与调度。

## 验证

- 主动清理查询仍能核实目标不存在并移出索引；覆盖重跑的双确认、取消、失败及部分执行恢复回归通过。
