## 状态场景覆盖

| 场景 | 已有证据 | 尚需核实 |
| --- | --- | --- |
| 无项目、无 PLAN、无 Worker | A1/A2 首屏隔离 | D1 全部就绪状态与附着禁用 |
| 单 Worker、多 Worker、部分离线 | API/CLI 隔离、进度既有回归 | C3 逐 Worker 同步展示与 D1 服务器状态；现场连接 |
| 运行中、停止中、已完成 | B1–B3 归并、精确停止、完成持久化和界面回归 | 真实服务器退出/重载 |
| 产物缺失、同步失败 | 现有完成撤销/同步身份检查；日志失败 C1 | C2/C3 操作范围和每台反馈；现场文件与传输 |
| 低流量 | 自动展示查询抑制、手动刷新和原采样时间回归 | 最终界面及现场网络 |
| 重载恢复、多窗口 | 持久完成/停止意图、本机队列单写者既有回归 | D0 项目内目录/服务窗口隔离；真实 Extension Host 重载 |

没有用本机 mock、源码检查或 VSIX 校验代替上表的现场项目；后续批次只更新受影响行及其证据。
