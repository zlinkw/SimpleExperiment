# 0.5.334 产物同步与 GPU 刷新交付

## 修改

修复产物同步期间运行 PLAN 被全局拒绝的问题。普通运行、API 和恢复入口不再使用产物复制作为提交门禁。job 完成后的有界产物复制与本机代码上传使用独立活动范围，不取消已有传输，也不清空代码校验凭据。默认代码上传同时排除 work_dirs 和 work_dir。

复制期间只在内存记录精确路径。覆盖、清理和文件树写操作在真实执行边界检查路径重叠；不同 job 可以继续提交，同一批产物仍保留写入保护和删除双确认。没有创建同步状态文件、历史副本或新调度算法。

显卡延迟来自 Worker 读取磁盘快照，以及根据旧任务登记将空闲采样延长为 60 秒加最多 30 秒抖动。现改为直接设备查询，HTTP 与采样线程合并同秒请求，仅在内存复用。正常采样间隔约一秒，仍受设备查询和网络耗时影响。任务快照使用独立线程，分钟级 GPU 历史保留原用途。隧道事件使用实际采样时间，迟到事件不能覆盖较新的直接查询。未修改科研环境和调度容量设置。
