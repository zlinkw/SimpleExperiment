模型：GPT-6.1 Terra high。先读 worker-common.md；不读总计划或其他批次。

独占候选文件（当前用户已授权移除相关功能源码）：

- src/PptPlotBridge.ts
- src/PptPlotBridge.legacy.ts
- src/features/PlottingContract.ts
- src/features/DatasetInspector.ts
- src/features/ExperimentConfigRecovery.ts
- src/features/ExperimentConfigRecovery.legacy.ts

先核每个文件实际归属、全部必要消费者和 Git 内容差异。PPT 源码可能在 git status 短暂显示已修改，但旧主会话已取回 HEAD 原字节；核实实际 diff，不盲目覆盖用户内容。完全删除专用文件按 safe-delete-paths/manual-cleanup-only 做全批精确预检，再逐个进入真实直接父目录，只对 ./直接子项 删除，不 Force，验证不存在。缺失/类型/链接/归属异常立即停止对应批次并报告。

这些文件含有一些普通路径助手。PlottingContract 中 planResultsArtifactRelPath 等若仍被基础业务真实引用，不得随意删掉；向调度提交确切依赖和最小迁移接口，由拥有消费者文件的执行者配合。禁止保留一个仍可连接 PPT 的兼容外壳。专用高级功能及代码确实无保留用途后才删除整个文件。

不改 test、scripts、docs、dist，不自行删除生成文件、旧配置、PPT 文档或消费项目数据。给调度列出需要后续移除的精确 dist 对应文件与清单引用。通过条件：专用源码移除、基础共享助手有明确归属、非测试消费者无悬空导入；集成闭包检查通过后才可验收。
