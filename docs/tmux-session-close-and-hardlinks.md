# 会话整组关闭与覆盖预览中的硬链接

## 0.5.321 会话按钮与当前任务识别

普通会话提供“关闭会话”和“清空标签页”：前者核对本轮服务器、完整窗口/pane 身份后，使用实际 session_id 关闭整个指定会话；后者先创建一个空闲终端，再关闭原标签页，保留会话。GPU 卡片关闭也使用整会话操作。旧逐标签入口和任务标签清理入口保持兼容。Agent 会话仍仅走其专用管理入口。

这些操作复用受认证、仅回环可达的 tmux 控制端点，不读取历史任务记录或进程 PID。不再因缺少旧 Agent 管理会话字段拒绝普通窗口关闭。操作后主动查询实际窗口列表，响应丢失不重复执行。旧 Agent 不支持新会话操作时明确提示更新，不静默退成逐标签关闭。

列表不再读取 worker_task_snapshot.json，改为读取 tmux 原生任务属性并按项目根和 Worker 核对归属；运行、排队和退出来自真实 pane 状态。带有已核实任务的 GPU 会话按实际 GPU 归入置顶卡片，不只依赖当前设置的名称前缀；相似前缀的无归属窗口仍不能冒充本项目任务。标签只保留一个可点击名称，地址和命令放入提示，普通会话使用紧凑的两个文字按钮。

手动派发在打开服务器/GPU 选择器之前暂停自动派发，取消或失败后释放暂停，避免选卡期间任务被自动派发而出现“任务已变化”。原 commandId 校验、已发送未知状态保护、停止后核实和覆盖确认继续保留。

回归包括缺失旧管理字段的报错重现、真实隔离 tmux 整会话关闭与保留空闲终端、其他会话/Agent 保护、原生任务归属、HTTP 查询、响应丢失、名称合并和选择器期间自动派发暂停。未操作生产 tmux 或科研产物。

## 0.5.319–0.5.320 会话整组关闭实现记录

其他会话行新增“关闭全部窗口”，不再要求逐个点击标签。点击后由 Host 实时核对服务器、会话、全部 windowId 和 paneId，弹窗列出精确目标，提醒窗口内进程会终止。取消不发送关闭命令。

复用 GPU 卡片的批量关闭协调器和单窗口执行器，按冻结的 windowId 逐项关闭；数字索引重排仍按原身份定位。列表变化、新增窗口、窗口替换或查询失败时停止并报告实际已完成数量，不扩大本次目标。不调用 kill-session、kill-server 或 PID 信号，不删除文件。Agent 会话保留其专用服务管理入口。普通会话由本次明确选择决定，不按 GPU 前缀推断归属。

回归执行真实渲染脚本、按钮点击和 Host 方法，验证整组请求、重复点击、服务器切换、取消、窗口集合变化、逐项进度及 Agent 保护。旧 GPU 入口和单标签关闭保留。

## 为什么运行 PLAN 会出现 cleanup.preview

运行流程会先读取已有产物，为“覆盖并重跑”准备只读预览。SHARED_HARDLINK 在这一阶段来自 SimpleSFTP 对实际文件硬链接数的检查，不证明存在旧协议状态，也不表示已经执行删除。只有用户选择覆盖并完成两次精确路径确认后，才进入删除旧产物与提交新任务。

SimpleSFTP 0.2.87 允许 confirmed_paths 删除中的普通文件具有多个硬链接，仅 unlink 用户确认范围内的名称；保留其他名称及其内容。仍拒绝符号链接、目录链接、越界、类型或 inode 变化，保留安全根、物理直接父目录和最短相对路径。普通移动、恢复和非路径授权流程维持原硬链接限制。

对已核实为硬链接的文件，冻结清单记录硬链接属性，后续核对继续使用同一分类。解除本批另一个名称造成的 inode ctime 变化不会令剩余文件失效；仍核对 device、inode、大小、mtime，实际写入引起这些信息变化仍拒绝。普通文件保留原 ctime 核对。扫描不追查其他硬链接位置，不读取大型权重内容，不新增服务器状态文件。

隔离夹具覆盖同目录多个名称、跨 job 冻结预览、最后一个内部硬链接、保留范围外源文件、内容变化拒绝及普通模式仍拒绝。开发未关闭真实窗口、删除生产产物或重跑任务。

## 0.5.320 / 0.2.88 批量删除进度

同一批路径原先并发数为 2，而远端执行器使用项目级 OS 互斥锁。第一个清理窗口仍执行时，第二个启动请求会被拒绝为 OPERATION_BUSY；原客户端又使用固定 15 秒总等待，结束后继续下一个路径，造成连续失败。

同步范围的路径批次改为串行。实际清理仍未结束或查询失败时，停止推进后续路径，不自动并发重发。SimpleSFTP 只将受管启动入口明确被 OS 锁拒绝、尚未建立窗口的结果返回 waiting/notStarted；允许重试同一 token、digest、operationId。执行响应丢失仍只主动查询，不能借等待分支重复启动。

活动清理窗口的查询附带实际已消失的冻结目录项数和字节数，仅扫描原清单中的路径、不读取权重内容、不跟随符号链接、不扫描清单外子树。客户端仅在这些数值前进时重置无进展等待预算，查询次数、时间戳和心跳不算进展。整批目标仍以窗口结束、目标实际不存在为完成依据，进度计数本身不能宣告删除完成。

回归覆盖实际临时文件消失后的数量/字节变化、处理时间超过旧总预算仍能完成、锁占用后沿原确认请求准入、无进展结束等待以及丢失响应不重发。最终交付包含此前会话整组关闭和硬链接预览修复；0.5.319 仅完成源码与本机打包，未安装或发行，统一交付 0.5.320。
