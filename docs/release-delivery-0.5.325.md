## 修复

旧部署流程同时上传两份运行文件，却仅重启并验收 Agent。独立 Scheduler 为保留任务而继续运行，内存中的旧代码因此没有更新。

Agent 启动现在读取本项目指定控制窗口的实际运行版本与两份 runtime 来源哈希；不一致时仅替换已核实的控制 pane。原控制窗口、取消围栏、已接收命令及全部任务窗口保留。新控制进程从现有窗口重建队列，既有运行任务不重启，历史状态文件不参与重放。

最新版 Agent 被复用时，部署入口仍主动读取 Scheduler 运行证据；控制进程过旧则自动重启 Agent，由其启动流程完成更新。健康检查与部署验收包含独立 Scheduler 的运行证据；缺失、归属不明、查询失败或重启未核实时明确报错，不能因磁盘文件或 Agent 版本匹配而宣称全部更新完成。

保留已接收任务的原调度参数；新提交使用当前设置。没有新增服务端作业状态文件、PID 管理、固定端口、科研检查或项目环境修改。
