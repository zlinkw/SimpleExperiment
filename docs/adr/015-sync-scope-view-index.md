# 项目文件索引与本轮证据

状态：已实现，现场部署与重载验收另记。

## 范围

只有“项目同步范围与状态”页面启动 Agent 全项目目录索引扫描。共享 ProjectFileIndex 同时接收文件树、本机代码清单、PLAN 本机及 Worker 源码核实，以及 SimpleSFTP 目录列表、目录存在性、文件统计和产物/代码内容清单的实际查询结果。其他操作仅记录原有必要读取，不因此启动全项目扫描或科研检查。索引不能授权写入、覆盖、删除或判定科研任务完成。

## 更新与读取

Agent 的 /api/sync-scope/index 只接收带 project-sync-scope 标记的页面请求，根目录固定为 Agent 已绑定项目。首次刷新才创建内存索引，目录扫描由独立线程和独立锁完成，HTTP 返回短请求票据；轮询与分页归入读取槽位，不占用任务控制槽位。

扫描只读取普通目录、文件类型、大小和修改时间，并计算各目录递归文件数及字节数。不打开文件内容、不计算数据集哈希、不写缓存文件或额外科研状态。保留机器状态排除、链接及挂载边界、条目和会话数量限制。

每次刷新明确请求新一代扫描。客户端必须等此请求完成，验证页面、请求、Agent 实例和 generation 后，才提交新快照。首次或重启后分批读取，后续只返回相对已确认 generation 的新增、变更和删除条目；无变化时传回空增量，而不是再次传输完整清单。同轮列表和目录计数共用一个读取。旧轮次、旧分页和连接换代回包不能覆盖新轮次。

主动刷新和文件操作结束请求新一轮；文件操作结束同时使相关页面的旧读取失效。同轮展开目录复用已请求的索引，切换模式保留各自状态，不反复取消全项目扫描。由其他程序造成的新增、删除或修改通过主动刷新核实。不引入全局轮询、后台文件监视器或 NFS 目录 mtime 永远不变的假设。目录读取前后身份变化会使本轮未知；目录时间不作为文件内容未变的证明。

本机也有页面内存索引。同轮文件树与汇总共用一次受保护的递归扫描，并复用扫描时的 stat，保留目录身份复核、链接和挂载边界。扫描只读元数据，不打开内容；共享记录按下节写入插件索引，不写入消费项目。目录邻接表支持展开时直接读取子项。连续 30 秒没有目录项进展时结束本轮等待并标为未知，可主动刷新；不能把超时或失败转换成空清单。

## 共享索引文件

每个工作区、节点和项目根使用插件 globalStorage 下的 file-index/<工作区指纹>/<节点及根指纹>.json，不放入消费项目，不同步到服务器。共享记录不含文件内容、原始指标、命令正文、口令或 token。重启或连接更换覆盖同一身份的索引文件，不自动删除文件。

schemaVersion=1。记录工作区、endpointId、projectRoot、连接指纹、generation、失效 epoch、失效时间和原因；每次观察保留 observationId、round、方法、精确范围及递归标记、metadata/SHA256 依据、查询开始与完成时间、有效期限、完整/部分/失败/已失效状态、文件/目录/未知计数。PLAN 核实另外绑定 projectId、runId、revision 和源码摘要。条目记录精确相对路径、固定类型、存在/缺失/未知、大小、mtime、可取得的 ctime/device/inode、实际读取获得的 SHA256 及来源观察身份。旧 Agent 没有的字段不伪造。

文件查询在实际读取前先落盘 reading 观察，并使同范围旧观察失效，读取结束再写完整、部分或失败。上传、下载、Worker 间传输和直接上传命令统一先刷新索引：本机对精确路径 stat，远端以 metadataOnly 分批读取本次涉及的文件/子目录；没有路径清单时只读根目录直属清单，不隐式全盘扫描。操作开始及 finally 继续失效，防止失败或部分写入遗留新鲜假象。映射下载分别记录远端路径和本机目标。刷新失败记录未知，实际操作仍必须自行完成既有路径、内容和安全核实；索引不是额外授权。token-only 删除执行复用紧邻的主动 inspect/preview，不从历史 token 或索引重新构造目标。Agent lifecycle 仍只失效，不为辅助服务重启扫描科研文件。

根文件仅保存观察、身份和布局，不重复保存所有后代；同名 .directories 目录下按相对目录指纹定位每层 JSON。每层仅包含目录自身、直属文件/目录、子目录索引引用及其文件数/字节/未知摘要。子目录内容变化由摘要指纹逐级传播，实际内容未变则不重写目录文件，仅更新根观察凭据。最多 8 个独立目录文件并发写入，全部完成后才发布根文件。浏览具体目录只需读取其直接索引，不解析全项目清单。

记录 maxDirectChildModifiedAtMs 和目录内容指纹。索引文件比直属文件新只能作为候选提示；删除、保留 mtime 的改写、深层变更、时钟差和 NFS 都可能漏判。目录清单/类型/大小/mtime/ctime/可用 inode 的本轮核实及范围完整性仍不可省略。Worker 文件时间与本机索引写入时间分别标明时钟域，不直接跨机器比较“谁最新”。

磁盘内容只作历史诊断；重启后不从磁盘恢复为当前证据。内存最多保留 60000 个条目、64 次观察，根观察文件最多 16 MiB；裁剪明确标记 storageTruncated，条目集合不等于完整覆盖声明，实际查询返回值不被裁剪。只有完整成功的同方法同范围查询能将该范围中原有条目更新为缺失；失败或不完整查询不能生成缺失。不同用途的 metadata 和 SHA256 不能相互替代。

默认每次确认都重新查询。只有调用方明确提供同一 round、相同用途/范围/绑定、同一连接和失效 epoch，且未超过 2 秒，才允许复用本轮结果。取消生命周期不同的订阅不共享中断控制。当前 PLAN、产物确认和代码核实保留实际 stat、内容指纹、最终 manifest 及身份检查，索引文件不替代它们。已有 job 完成确认仍由原队列规则维护，索引过期或查询失败不会撤销已确认完成。

## 失效与更新时机

| 触发 | 行为 |
| --- | --- |
| 首次打开、主动刷新、文件操作后 | 请求新轮次，列表与汇总共用该轮扫描 |
| 同轮展开、切换模式 | 复用各自轮次，不取消后重扫；已过期则请求新轮次 |
| 页面观察完成 30 秒 | 仅标记过期和未知，下一次刷新/展开重新读取；不后台循环扫描 |
| SFTP 上传、下载、传输、删除或 Agent lifecycle | 开始前及结束后，包括失败，失效共享索引；通知已打开文件树取消旧读取，旧回包不能恢复状态 |
| 同步范围或保留版本改变 | 失效相关快照，重新核实后才显示本轮状态 |
| 主动查询发现任务执行/产物实际变化，或保存的 job 产物事实变化 | 按精确输出、CSV 和产物路径失效；不以其他 job 的变化阻断不相交的 PLAN 源码查询 |
| 工作区、节点根、连接实例或 Agent generation 改变 | 隔离身份；迟到的旧连接/旧轮次不能覆盖新证据 |
| 断线、权限失败、取消、无进展超时 | 本轮未知/失败，不续期、不冒充空目录；显式新轮次可重试 |
| 外部编辑或外部程序写入 | 页面在有效期后显示过期；确认入口每次实际查询，不只依赖监听、目录 mtime 或旧缓存 |

操作状态位于文件树上方。每个本机或 Worker 位置持续保留本轮等待、读取、完成、部分未核实或失败状态及已读数。只在完整成功索引没有发现目标时显示确认缺失；索引未完与查询失败分别显示。树内一键删除和底部多选删除复用现有删除位置选择及完整路径双确认，不跳过精确父目录检查。

关闭页面取消该页读取并释放会话。扫描会检查会话取消，空闲会话 120 秒后失效；有界内存缓存按访问回收，不持久化文件清单。失败不发布旧快照，不更新时间冒充本轮成功，允许下一轮重新读取。

## 兼容与完整核实

旧 Agent 不支持索引时，页面通过 SimpleSFTP 0.2.97 的 metadataOnly 读取兼容。真实索引失败显示未知，不把错误当作旧协议或空目录。旧版 SimpleSFTP 未声明 metadataOnly 时拒绝自动全项目哈希。

目录缺失和差异计数不受传输范围勾选影响。默认差异表示大小或修改时间不同，不能当作内容 SHA256 不同；页面保留主动内容比较。实际同步及删除继续进入原完整核实、全部启用 Worker、精确路径和删除双确认流程。

默认隐藏本轮比较信息一致的文件和子树，查询失败、未收到清单和未完成的路径始终可见。“显示一致项”只改变显示，不改变同步范围或勾选。异常筛选也保留查询未知项。失败响应携带的空 files、无效清单及显式未完成清单都不能证明文件缺失；主动内容比较沿用同一失败边界。

同一文件的副本按实际大小、修改时间及类型合并显示位置名；主动内容比较完成后按完整 SHA256 和时间分组。目录只合并汇总信息相同的展示行，不将相同计数解释为内容相同。确认缺失、查询失败、读取中和本轮未列出分别显示，错误详情放在提示中。合并展示仍保留各服务器独立来源和操作按钮，不把分组当作操作目标或删除授权。

## 验证

隔离测试执行真实扫描器和从生产 runtime 提取的 POST 方法，不导入或运行整个 Agent。覆盖增删改、无变化空增量、首次全量、实例重启、分页换代、迟到响应、权限失败、页面释放及读取槽位分类。所有 Python 子进程有 10 秒上限，单文件 node:test 串行且有 20 秒上限。
