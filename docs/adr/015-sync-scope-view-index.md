## 0.5.387 批次确认与并行停止

运行进度的勾选批次、全部 Plan 及中止所有 Plan 共用一个入口。先有界并行准备全部精确目标，显示含项目、Plan、Worker、commandId、job 和输出路径的完整批次，只确认一次；取消不发出停止或队列清理命令。确认后最多 4 个 Plan 并行执行，单个失败保留其未确认记录，其他已授权的独立 Plan 继续；任务和文件目标不自动扩大。已结束历史只清除本机记录，训练产物保留。单项原有入口继续保留。

批次使用一个调度停止围栏；全部队列写入在既有串行、文件租约和原子发布内读取最新状态，再提交本 Plan 的增量，不能用旧整队列覆盖其他 Plan 的进度或新提交。本机历史及截断时间也串行合并。批次自身写入不互相废止；批次、项目或精确目标变化时拒绝迟到写入，不按名称前缀关闭窗口，不产生文件删除授权。永久删除仍保留原路径双确认及直接父目录保护。

隔离夹具执行真实生产准备/停止/清理方法，覆盖单次确认、8 个 Plan 的 4 路重叠停止、共享队列和历史增量、部分失败、取消、项目切换、新目标拒绝及停止全部的路由；实际生产原子写入器另测并行增量和围栏在 rename 重试中失效。验证不停止用户真实任务或修改科研文件。

## 0.5.386 自动内容校验

文件状态页每轮先发布实时元数据索引及各节点完成状态，再自动校验内容，无需点击比较按钮。第一次为没有可信哈希的文件建立基线；后续仅请求本轮身份变化的文件。页面内复用绑定项目、连接、Agent 实例及逐条变更版本的证明；重载后重新核实文件身份，再由本机持久缓存和 SimpleSFTP SQLite 缓存复用 SHA256。大小相同、修改时间不同且 SHA256 相同显示一致；等长但内容不同仍显示差异。

本机一次加载和保存哈希缓存，内容读取并发限制为 2；服务器按精确文件路径分批，每批最多 256 项及 64 KiB，不将其压缩成父目录递归扫描。配套 SimpleSFTP 0.2.101 返回校验时的 ctime、device、inode。Agent 增量条目版本处理毫秒时间相同但底层文件已变化的情形。元数据与哈希身份不一致、读取失败、取消或换代一律显示未知，不能据此确认缺失。删除从新索引移除旧正证明，重新创建需重新核实。

此缓存只加速状态展示；PLAN 校验、产物确认、同步和删除继续走原主动核实，页面缓存不能授权写入或替代双确认。保留手动“比较文件内容”入口用于重新校验。生产摘要、真实本机新进程缓存、实际 Python/SQLite 清单夹具覆盖首次、无变化、单文件变化、删除重建、离线、取消及重载复用；这些是隔离夹具证据，不是用户服务器现场测速。

同版本运行进度为每张 Plan 卡片直接提供复选框，支持全选及中止并清理勾选/全部 Plan，选择状态随 Webview 恢复。顶部中止可用性纳入分布式活动、未知和等待队列，不再只依赖旧本机操作记录。批次逐 Plan 沿用已有精确停止、主动查询和两次确认，遇取消、失败或项目切换停止后续批次；清理队列和进度记录，保留训练产物。

## 范围

“项目同步范围与状态”页面及其批量候选展开主动请求 Agent 全项目目录索引；首次建立基线，后续按目录变化刷新。文件操作前后可主动刷新已建立的原生增量基线；未建立或非原生基线的独立操作保留精确范围查询，不隐式建立全项目索引。共享 ProjectFileIndex 同时接收文件树、本机代码清单、PLAN 本机及 Worker 源码核实，以及 SimpleSFTP 目录列表、目录存在性、文件统计和产物/代码内容清单的实际查询结果。索引不能授权写入、覆盖、删除或判定科研任务完成。

## 更新与读取

Agent 的 /api/sync-scope/index 只接收带 project-sync-scope 标记的页面请求，根目录固定为 Agent 已绑定项目。首次刷新才创建内存索引，目录扫描由独立线程和独立锁完成，HTTP 返回短请求票据；轮询与分页归入读取槽位，不占用任务控制槽位。

扫描只读取普通目录、文件类型、大小和修改时间，并计算各目录递归文件数及字节数。不打开文件内容、不计算数据集哈希、不写缓存文件或额外科研状态。保留机器状态排除、链接及挂载边界、条目和会话数量限制。

每次刷新明确请求新一代扫描。客户端必须等此请求完成，验证页面、请求、Agent 实例和 generation 后，才提交新快照。首次或重启后分批读取，后续只返回相对已确认 generation 的新增、变更和删除条目；无变化时传回空增量，而不是再次传输完整清单。同轮列表和目录计数共用一个读取。旧轮次、旧分页和连接换代回包不能覆盖新轮次。

主动刷新和文件操作结束请求新一轮；文件操作结束同时使相关页面的旧读取失效。同轮展开目录复用已请求的索引，切换模式保留各自状态，不反复取消全项目扫描。由其他程序造成的新增、删除或修改在下一次主动查询核实。不引入全局轮询或 NFS 目录 mtime 永远不变的假设。目录读取前后身份变化会使本轮未知；目录时间不作为文件内容未变的证明。本机变化监听的范围和回退见下节。

## 0.5.385 修改时间不作为内容差异证据

快速文件信息比较原先按“大小 + 修改时间”分组，导致同步工具未保留时间、服务器时钟或人工 touch 后，即使字节完全相同也呈现红色差异。现在仅文件大小不同或本轮确认缺失计入文件信息差异；相同大小但时间不同单列为“仅修改时间不同，内容待比较”，以灰色显示，不记入文件/目录差异数、待同步数、读取未知数或索引未完成。尚未比较内容时不会据大小冒充 SHA256 一致。

## 0.5.382 批量删除的读取失效竞态

批量删除并非由报错中的文件大小触发固定上限。树中执行清理只发送 token，原通用文件操作包装器没有其节点和路径上下文，因此每台 Worker 的每次删除都会使全部节点的全项目观察失效。其他节点或后台主动观察交错时，删除前后正在执行的 `files.cleanup.inspect` 会正确拒绝旧观察，但原调用链将这种可恢复的只读失效直接报告为删除失败。

树删除调用将已经确认的服务器和相对路径通过独立的本机参数传给操作包装器，仅使实际 Worker 的该子树失效；上下文不进入 SFTP RPC，不参与删除授权，也不更改 token、完整路径双确认、类型或父目录校验。未知范围的其他操作继续保守失效。当前节点同一子树的在途旧证据仍必须拒绝，不能靠缩小失效范围恢复旧证据。

存在性读取同时复用完整来源的网络身份，避免把 SSH 别名当作新连接替换页面索引所有者。实际传输仍使用原配置的别名；不改远端节点、根路径或 RPC 参数。真实连接更换仍拒绝旧读取。

仅本调用链的只读存在性/执行窗口检查遇到 `FILE_INDEX_INVALIDATED_DURING_READ` 时，丢弃该次结果，间隔 250 ms 重新主动查询，最多三次。读取前和已完成删除后的检查均适用；预览、确认、执行及进度查询不因该错误重放，连接变化、离线、保护失败等不重试。三次仍变化则明确未核实，目标重新创建也不认定成功，更不能重新发送删除。大目录原有清理窗口与真实条目/字节进度观察保留，不新增固定总体超时。

每个工作区、节点和项目根使用插件 globalStorage 下的 file-index/<工作区指纹>/<节点及根指纹>.json，不放入消费项目，不同步到服务器。共享记录不含文件内容、原始指标、命令正文、口令或 token。重启或连接更换覆盖同一身份的索引文件，不自动删除文件。

schemaVersion=1。记录工作区、endpointId、projectRoot、连接指纹、generation、失效 epoch、失效时间和原因；每次观察保留 observationId、round、方法、精确范围及递归标记、metadata/SHA256 依据、查询开始与完成时间、有效期限、完整/部分/失败/已失效状态、文件/目录/未知计数。PLAN 核实另外绑定 projectId、runId、revision 和源码摘要。条目记录精确相对路径、固定类型、存在/缺失/未知、大小、mtime、可取得的 ctime/device/inode、实际读取获得的 SHA256 及来源观察身份。旧 Agent 没有的字段不伪造。

文件查询在实际读取前先落盘 reading 观察，并使同范围旧观察失效，读取结束再写完整、部分或失败。上传、下载、Worker 间传输和直接上传命令统一先刷新索引：本机对精确路径 stat，远端以 metadataOnly 分批读取本次涉及的文件/子目录；没有路径清单时只读根目录直属清单，不隐式全盘扫描。操作开始及 finally 继续失效，防止失败或部分写入遗留新鲜假象。映射下载分别记录远端路径和本机目标。刷新失败记录未知，实际操作仍必须自行完成既有路径、内容和安全核实；索引不是额外授权。token-only 删除执行复用紧邻的主动 inspect/preview，不从历史 token 或索引重新构造目标。Agent lifecycle 仍只失效，不为辅助服务重启扫描科研文件。

根文件仅保存观察、身份和布局，不重复保存所有后代；同名 .directories 目录下按相对目录指纹定位每层 JSON。每层仅包含目录自身、直属文件/目录、子目录索引引用及其文件数/字节/未知摘要。子目录内容变化由摘要指纹逐级传播，实际内容未变则不重写目录文件，仅更新根观察凭据。最多 8 个独立目录文件并发写入，全部完成后才发布根文件。浏览具体目录只需读取其直接索引，不解析全项目清单。

记录 maxDirectChildModifiedAtMs 和目录内容指纹。索引文件比直属文件新只能作为候选提示；删除、保留 mtime 的改写、深层变更、时钟差和 NFS 都可能漏判。目录清单/类型/大小/mtime/ctime/可用 inode 的本轮核实及范围完整性仍不可省略。Worker 文件时间与本机索引写入时间分别标明时钟域，不直接跨机器比较“谁最新”。

磁盘内容只作历史诊断；重启后不从磁盘恢复为当前证据。内存最多保留 60000 个条目、64 次观察，根观察文件最多 16 MiB；裁剪明确标记 storageTruncated，条目集合不等于完整覆盖声明，实际查询返回值不被裁剪。成功的完整目录枚举可将本轮覆盖范围内未返回的旧条目更新为缺失，范围外不受影响；文件清单只覆盖文件，不能据此推断空目录不存在。其他用途只在同方法同范围或主动查询明确 missing 时确认缺失。失败或不完整查询不能以遗漏生成缺失。条目的有界来源范围独立于 64 条观察历史，历史裁剪不影响新轮次删除核实。不同用途的 metadata 和 SHA256 不能相互替代。

连接身份按当前客户端会话、实际 host、数值端口和用户名归一，服务器 DTO 的 networkHost 与 host 视为同一地址，删除节点没有 networkHost、使用 root 替代 remotePath 或字符串端口不会换代。真正换机或连接换代仍隔离；恢复到先前配置创建空的新 owner，不复活旧对象和缓存回包。cleanup.inspect 返回的目标通常只有 absolutePath、type 和 missing，索引核对其与请求中的精确相对路径相符后记录，不要求响应重复 relativePath。确认目录缺失时，其已知后代和逐级计数同时更新；查询成功存在或缺失的目录状态也写入索引。

删除执行器已完成后，再主动 inspect 同一精确目标，把最终存在性写回共享索引，然后由页面新轮次重建列表和汇总。查询失败或发现目标已重新出现仅报告未核实，不重复删除、不扩大目标；原完整路径双确认和父目录规则不变。

默认每次确认都重新查询。只有调用方明确提供同一 round、相同用途/范围/绑定、同一连接和失效 epoch，且未超过 2 秒，才允许复用本轮结果。取消生命周期不同的订阅不共享中断控制。当前 PLAN、产物确认和代码核实保留实际 stat、内容指纹、最终 manifest 及身份检查，索引文件不替代它们。已有 job 完成确认仍由原队列规则维护，索引过期或查询失败不会撤销已确认完成。

## 失效与更新时机

| 触发 | 行为 |
| --- | --- |
| 首次打开、主动刷新、文件操作后 | 请求新轮次，列表与汇总共用该轮扫描 |
| 同轮展开、切换模式 | 复用各自轮次，不取消后重扫；已过期则请求新轮次 |
| 页面观察完成超过 30 秒 | 保留索引完成状态及明确标注时间的上次查询结果；下一次展开或切换模式主动请求新轮次，不通过时钟清空整棵树，不后台循环扫描 |
| SFTP 上传、下载、传输、删除或 Agent lifecycle | 开始前及结束后，包括失败，失效共享索引；通知已打开文件树取消旧读取，旧回包不能恢复状态 |
| 同步范围或保留版本改变 | 失效相关快照，重新核实后才显示本轮状态 |
| 主动查询发现任务执行/产物实际变化，或保存的 job 产物事实变化 | 按精确输出、CSV 和产物路径失效；不以其他 job 的变化阻断不相交的 PLAN 源码查询 |
| 工作区、节点根、连接实例或 Agent generation 改变 | 隔离身份；迟到的旧连接/旧轮次不能覆盖新证据 |
| 断线、权限失败、取消、无进展超时 | 本轮未知/失败，不续期、不冒充空目录；显式新轮次可重试 |
| 外部编辑或外部程序写入 | 页面在有效期后显示过期；确认入口每次实际查询，不只依赖监听、目录 mtime 或旧缓存 |

操作状态位于文件树上方。每个本机或 Worker 位置持续保留本轮等待、读取、完成、部分未核实或失败状态及已读数。只在完整成功索引没有发现目标时显示确认缺失；索引未完与查询失败分别显示。树内一键删除和底部多选删除复用现有删除位置选择及完整路径双确认，不跳过精确父目录检查。

关闭页面取消该页读取并释放会话。扫描会检查会话取消，空闲会话 120 秒后失效；保留最多两代有界内存快照及持久加速基线，但不保留已关闭页面的当前证据身份。失败不发布旧快照，不更新时间冒充本轮成功，允许下一轮重新读取。

## 兼容与完整核实

旧 Agent 不支持索引时，页面通过 SimpleSFTP 0.2.97 的 metadataOnly 读取兼容。真实索引失败显示未知，不把错误当作旧协议或空目录。旧版 SimpleSFTP 未声明 metadataOnly 时拒绝自动全项目哈希。

目录缺失和差异计数不受传输范围勾选影响。默认差异表示大小或修改时间不同，不能当作内容 SHA256 不同；页面保留主动内容比较。实际同步及删除继续进入原完整核实、全部启用 Worker、精确路径和删除双确认流程。

默认隐藏本轮比较信息一致的文件和子树，查询失败、未收到清单和未完成的路径始终可见。“显示一致项”只改变显示，不改变同步范围或勾选。异常筛选也保留查询未知项。失败响应携带的空 files、无效清单及显式未完成清单都不能证明文件缺失；主动内容比较沿用同一失败边界。

同一文件的副本按实际大小、修改时间及类型合并显示位置名；主动内容比较完成后按完整 SHA256 和时间分组。目录只合并汇总信息相同的展示行，不将相同计数解释为内容相同。确认缺失、查询失败、读取中和本轮未列出分别显示，错误详情放在提示中。合并展示仍保留各服务器独立来源和操作按钮，不把分组当作操作目标或删除授权。

## 持久增量加速

0.5.377 将操作后重读和手动刷新收敛到同一索引启动流程。删除完成或部分失败时立即发起每个模式的新轮次摘要，与目录列举共用本轮基线，状态栏显示真实索引阶段、各位置读取项数和完成/失败状态。无需等待目录列举结束才发起摘要；部分结果发布不覆盖最近一次真实进度，部分操作失败的提示与索引进度同时显示。迟到回包隔离、增量基线和删除后的实际文件树重读保持原规则。

0.5.376 补齐真实变更通知后的自动核实。已完成页面收到文件或同步版本记录变更后，先把旧事实转为未知，200 ms 内的节点通知合并为一次新轮次，主动使用既有增量基线重新读取，不再停留在“已过期，请刷新”。未激活模式保留待核实标记，切换时读取；页面操作期间延后自动刷新，完成走原操作后重读，取消则恢复自动核实。旧轮次回包不能恢复旧缺失；失败仍显示失败/未知，不自动重复执行文件操作。同步保留记录无实际变化时既不写盘也不广播失效；实际变化先持久化，再按变化路径通知。PLAN、产物和删除的主动核实与双确认边界不变。

0.5.375 区分索引已建立与某一轮查询时间，不再使用页面 30 秒计时器将全部位置改为未完成。状态栏标注上次读取/校验时间；超过观察窗口后的主动展开、切换模式和手动刷新都会开启新轮次。实际文件操作的失效通知、失败未知、迟到回包拒绝及操作前的主动核实保持有效。

页面 local.metadata/agent.metadata 可将诊断目录 JSON 的落盘放到后台，文件系统已核实的结果先发布。持久加速基线及服务器游标仍先核实；诊断索引不授权操作，因此数千个分片 fsync 无需阻塞完成状态。后台写入保留串行队列、8 路分片写入、当前 owner 校验及根文件最后发布。其他读取即使传入后台标记也不放宽原有读取前 reading 落盘和确认边界，PLAN、产物、清理与文件操作不走此例外。已失去 owner 的旧写入静默停止，不把正常连接换代误报为持久化故障。

0.5.374 将加速基线和确认凭据分开。共享观察文件继续只作历史诊断；加速基线可以重载复用，但必须先完成本轮文件系统校验或 Agent 游标确认，才能转为本轮完整结果。没有网络回应、索引断层或尚在读取时不发布历史缺失。

本机在扩展全局存储内保存带根目录设备/inode 身份、策略版本、顺序号和事务摘要的 UTF-8 增量日志。每次最多追加一笔变更，64 笔或 16 MiB 后原子压缩为基线；不为每层重复保存整个子树。重载后逐目录核验身份，只枚举发生变化的目录；已有文件的 stat 采用有界并发，保留类型、链接、设备、规范父目录和扫描前后身份检查。目录 mtime 无法发现已有文件内容修改，因此没有连续可靠日志时，包括 Windows 和网络挂载，仍主动 stat 已知文件；不会为了速度仅信监听或时间戳。此实现不依赖额外 Everything 安装或管理员服务。

Worker 在本节点既有 Agent 状态目录内保存 SQLite 事务基线，变更批量 upsert/delete，WAL 提交后才供下一次恢复使用。Linux 已识别的本地文件系统使用原生 inotify，每个目录监听在枚举前建立，刷新前后主动排空通知；只重读变化目录，目录汇总线性自底向上计算。队列溢出、监听失效、取消、查询失败和 Agent 重启都会触发保守实时校验；至少每 30 秒的主动刷新也执行全量身份核对。网络挂载、未知文件系统或监听额度不足始终采用实时校验，不宣称通知覆盖完整。没有页面请求时不后台轮询或执行科研检查。

关闭页面或重载 VS Code 后，Agent 保留最多两代快照；本机保存绑定规范节点连接的游标及文件基线。新页面先主动刷新服务器，只在同一 Agent 实例接受原 generation 时应用增量；游标已淘汰或 Agent 换代则重新接收完整基线。磁盘内容从不直接标为本轮完成。节点名相同但 host、port、user 或项目根变化不能复用旧游标。

共享目录 JSON 维护直属条目分组和子目录引用；单个条目改变只重算其直接父目录与祖先，无变化刷新不遍历全树重新生成所有摘要。删除后的明确缺失更新后代、计数和相关目录摘要；未列出、失败和读取中不生成删除记录。内存加速基线在文件操作后的下一次主动读取核实删除，Worker 通过变更通知或实时校验同步更新。

PLAN 源码、产物确认和代码/产物内容清单继续走原主动 stat、SHA256、manifest 和精确身份核实。加速器不读取或复用它们的历史确认结果，也不替代删除双确认。测试用目录移入排除区模拟真实文件系统中的路径消失，不对用户文件执行新的永久删除。
