# 多选 PLAN 批量提交

实验准备区保留当前 PLAN 下拉框，另提供可滚动的勾选列表、“全选筛选结果”“清空选择”和“运行所选计划”。当前 PLAN 用于单独查看和操作，与批量勾选独立。搜索、状态筛选和排序沿用原控件；筛选外仍勾选的 PLAN 会明确列出，不会悄悄遗漏或自动加入。已选数量实时展示。

勾选只在当前面板内存中保留。状态刷新或筛选不会丢失选择；切换项目、文件从扫描结果消失或重载会清除对应选择。空选择禁止运行，不回退成运行全部。原“运行全部计划”和单 PLAN 入口保持不变。

点击后冻结明确路径集合，按扫描顺序逐个复用现有 runPlan 流程，包括同步、校验、预演、Worker 检查、必要的产物覆盖双确认、提交和主动查询。只等待每个 PLAN 的提交流程，不等待训练完成；已提交任务由原调度器并行调度。没有增加科研环境或数据检查，也没有新的删除协议或产物状态文件。

任一计划失败、取消、结果未知或工作区/目标配置变化时，停止后续提交，保留已处理任务并显示范围。未知请求保留原操作身份，不自动重新提交。重复点击正在执行的批次不会产生新的启动请求。整个选定路径集合先与最新工作区扫描结果核对，任意路径缺失则整批不开始。

API/CLI 复用原 invoke 入口，仅适用于 0.5.340 及以上版本，示例参数如下。调用前读取实时 capabilities 的 version；旧版不支持此子集参数，不能向旧版发送此请求。confirm 不代替产物永久删除的完整路径双确认。

```json
{
  "command": "runAllPlans",
  "selectionOnly": true,
  "planFiles": ["experiments/plans/comparison/a.yaml", "experiments/plans/comparison/b.yaml"],
  "confirm": true
}
```

使用 `simpleex api invoke --json <参数文件>` 或原 SimpleExperiment API CLI。显式提供 planFiles 时始终按子集处理，包括空值或非法值；不会扩大成全量。API 返回逐 PLAN 的原 operationId、提交流程状态、说明及未提交列表。提交流程结束不代表任务已经运行或成功，实际状态继续以服务器主动查询为准。
