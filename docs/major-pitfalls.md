# 长期大踩坑

本文件独立于需求代次轮换。当前无可核实的固化条目。

## 登记与核实

同一问题跨会话、跨代累计真实返修次数。一次返修指验收指出问题后实现修改并再次提交；同一提交对应的多份日志、失败测试或重复消息只计一次。不同问题分别计数，不按关键词合并。候选的问题身份、已核次数或“未知”、每次提交与验收证据位置留在执行登记；旧代淘汰前结转仍需的计数和定位。

累计至少三次只触发复盘候选，不证明根因。调度组织核证，独立验收核实核心机制和有效修法后才固化；未解决、根因未证或次数不明的事项继续留在执行登记。后续增加次数也须有真实证据。

固化条目应包含稳定问题标识、典型表现、经验证核心机制、有效修法及验证、适用边界、原始证据引用和累计返修次数。不复制完整日志或逐次过程。
