# tmux 作业生命周期实施

当前基线 0.5.305，用户批准 Scheduler/tmux/最终产物的主动查询方案。

固定边界：不访问生产服务器，不训练，不删除真实产物；保留用户工作区改动。
自动同步、静态入口探针、全部 Worker 就绪检查、输出目录创建、指标内存读取和独立更新必须保留。
新任务无 attempt，无科研规则或环境依赖校验；项目负责输出目录，插件不使用正式目录文件锁。
